# Release notes — v0.4.0

Released: 2026-02-17 (pending merge)

## Highlights
- Vectorized backtester: clearer `signal → exposure → weights` pipeline and new portfolio schemes (market‑neutral, long‑only, top‑N).  
- Multi‑horizon IC decay, factor correlation matrix + clustering, and orthogonalization utilities.  
- New backtest metrics: Sortino, Calmar, win rate.  

## Migration notes
- No breaking changes expected for standard user APIs. If you rely on internal or edge-case APIs, please review the detailed CHANGELOG and tests.
